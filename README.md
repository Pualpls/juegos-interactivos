# Juegos Interactivos Escolares - 3° de Primaria

Repositorio público de recursos lúdicos interactivos y multimedia para tercer grado de educación primaria de la Escuela Primaria Federal "José Clemente Orozco" (Sayula, Jalisco).

## 🚀 Acceso en Línea

El portal interactivo completo está disponible en GitHub Pages:
**[https://pualpls.github.io/juegos-interactivos/](https://pualpls.github.io/juegos-interactivos/)**

## 🛠️ Características Técnicas
* **Tecnología:** HTML5, Vanilla JavaScript y CSS moderno.
* **100% Offline y Estático:** Sin backend, sin dependencias externas pesadas, sin rastreadores ni publicidad.
* **Optimizado para Pantalla Táctil:** Diseñado para pantalla táctil Computerland del aula.
